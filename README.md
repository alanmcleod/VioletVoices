# Violet Voices

A self-contained browser app for sketching and playing SATB chord progressions.

## Main features
- Choose key, major/minor mode, time signature and tempo
- Enter soprano, alto, tenor and bass notes separately
- Use the key signature or explicitly choose flat, natural or sharp
- Choose a duration for each chord
- Edit, duplicate, insert and delete chords
- Piano-like browser playback
- Automatic browser saving
- Export and import progression files
- Basic warnings for voice crossing, range and wide upper-voice spacing
- Installable as a small web app

## Using it
Open `index.html` in a browser, or upload the whole folder to GitHub Pages.
For offline installation, serve it over HTTPS so the service worker can cache the files.
